开始前，
你可能想知道。

从哪里开始最方便？+

想先体验记录和日历，可以直接打开网页端。希望使用原生桌面组件、托盘提醒和自动更新，下载 Windows 版后解压，运行 Shixu.exe。

网页和桌面会自动看到同一份记录吗？+

需要登录同一个账户。在网页或桌面工作台左下角点击“登录账户”，注册 Fairy 账户，再在另一端用相同的用户名和密码登录。登录后，事项和分类会在设备上加密后自动同步。

助手需要 API 吗？+

基础查询、明确记录和本地规则排期不需要 API。桌面端更复杂的云模型能力需要在设置中配置模型和有效密钥，模型费用由所选服务决定。网页端目前使用本地规则助手。

关闭网页后，还会提醒我吗？+

网页提醒需要页面保持打开。需要托盘提醒时使用 Windows 版；完全退出应用或设备休眠期间也不保证通知送达。
